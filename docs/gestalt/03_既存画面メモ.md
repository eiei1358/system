# 既存画面メモ（チーム作成のHTML画面・スクリーンショット由来）

> 共有された画面イメージ（プレーンHTML）を、後続作業の参照用に記録したもの。
> 私（Claude）が作成した `prototype/admin/` のスタイル付きプロトタイプとは別系統の、
> シンプルな実装イメージ。**画面遷移と項目の確定情報**として扱う。

---

## UC710 統計情報閲覧

### 画面1：統計情報閲覧（集計条件）
- 見出し：**統計情報閲覧** ／ セクション「集計条件」
- 入力項目：
  - **集計観点**：プルダウン（例：出品数 …）
  - **期間**：日付（`年/月/日`）〜 日付（`年/月/日`）
- ボタン：**集計する**
- リンク：**管理メニューへ戻る**

### 画面2：統計情報結果（集計結果）
- 見出し：**統計情報結果** ／ セクション「集計結果」
- 結果テーブル（項目／件数）：

  | 項目 | 件数 |
  |---|---|
  | 出品数 | 120件 |
  | 成約数 | 95件 |
  | 成約率 | 79% |

- セクション「グラフ表示」：画像プレースホルダ＋注記
  「※ここに棒グラフや折れ線グラフを表示」
- リンク：**条件を変更して再表示** ／ **管理メニューへ戻る**

> 遷移：集計条件 →[集計する]→ 集計結果 →[条件を変更して再表示]→ 集計条件

## UC709 利用制限

## メモ・整合性の所感

- 全画面に共通で **「管理メニューへ戻る」** リンクがある（管理者メニュー=UC701 画面がハブ）。
- 完了画面のパターンが共通：「〇〇しました。」＋「一覧へ戻る」「管理メニューへ戻る」。
  708 だけでなく 707（物品削除）/709 完了も同じ型に揃えると統一感が出る。
- 利用制限の社員番号は **10001 形式**（数値5桁）。一方 `prototype/admin/index.html` の
  サンプルは **E2024001 形式**。**社員番号のフォーマットは要統一**。
- 統計の集計観点は要件書どおり「出品数／成約数／成約率／カテゴリ別／時系列」を網羅予定。
  グラフは現状プレースホルダ（実装時に棒/折れ線を描画）。
- これらはプレーンHTML（CSSなし）。デザインを揃える場合は `prototype/admin/` の
  共通スタイルへ寄せられる。
