## 本システムの目的

社員間の物品（書籍・IT 機器など）のやりとり（**譲渡**）情報を提供する仲介システム。

- やりとりは**有償・無償を問わない**。
- 「不要物を捨てるより誰かに役立てたい社員」と「費用を抑えて学びたい社員」を仲介。
- **物品や金銭の受け渡し自体には関与しない**（情報提供と証跡管理に徹する）。
- 譲渡価格の決め方は 3 種: **無償 / 出品者希望金額 / オークション方式**。

## ユーザ種別と利用内容

### A) 社員
- 譲渡したい物品の登録
- 登録された物品の検索
- 譲渡に関するメッセージのやりとり
- 登録された物品への応募（オークションへの入札を含む）

### B) 管理者
- 人事システムから受け取った新入社員情報の登録と社員情報管理
- 物品のカテゴリや検索キーの登録・管理
- 不適切な物品やメッセージの監視
- システム利用状況の管理

## 機能一覧（17 項目）

| # | 機能 | 要点 |
|---|---|---|
| 1 | ユーザの認証 | ログイン時にパスワード認証。**パスワードは暗号化保存**。社員/管理者は属性で識別。**ログイン成功時に最終ログイン日時を表示**。 |
| 2 | 人事システムからの新入社員情報登録 | **CSV** で受領 → 登録。**ランダム仮パスワード**を発行しメール通知。最低項目: 社員番号・氏名・所属部門・メールアドレス（追加項目は人事担当と協議可）。 |
| 3 | 社員情報の管理 | 管理者が社員情報の変更・削除。管理者は**パスワードリセット**可（仮 PW 発行→メール）。 |
| 4 | パスワードの管理 | ログイン後に本人が自由変更。忘却時はログイン前に**リセット要求**可（仮 PW 発行→メール）。 |
| 5 | アカウントの無効化 | **3 回以上連続でパスワード誤り**で無効化→ログイン不可。解除はパスワードリセット。 |
| 6 | パスワードの強制変更 | **仮パスワードでのログイン時**、または**3 か月以上未変更**のときログイン時に変更を強制。 |
| 7 | カテゴリ/検索キーの登録・管理 | 管理者がカテゴリ・よく使う検索キーを登録・管理。 |
| 8 | メッセージのやりとり | 質問・交渉・連絡・管理者通知をメッセージ機能で。**当事者のみ公開**。受信者へ**メールでリアルタイム通知**。 |
| 8'| 譲渡したい物品の登録 | 付加情報・**商品状態(新品/新品同様/中古/ジャンク)**・写真・希望金額・**条件(無償/有償/オークション/価格交渉可否/受渡方法)**・カテゴリ・検索キー・**登録期限**を登録。期限内に未成約なら新期限で**再登録可**。 |
| 9 | 物品の検索 | カテゴリ・検索キー・商品状態・成約済み・譲渡完了・登録日時順・期限順・期限切れ含む等で検索し一覧表示。 |
| 10 | 物品への応募 | 応募 ＋ 出品者とメッセージ相談可。成立で出品者が**成約済み**に（以後応募不可）。**期限切れには応募不可**。 |
| 11 | オークション方式 | 登録期限までの**最高金額提示者と成約**。現在の最高金額を閲覧可。1 人でも提示があれば**期限時点で成約済み**。 |
| 12 | 成約後の処理 | 成約時、出品者・成約応募者の双方にメール通知。受渡方法をメッセージで調整。完了後、双方が**譲渡完了登録**（完了の証拠）。 |
| 13 | 管理者による監視 | **曖昧検索**で不適切な登録・やりとりを監視（いつでも可）。**NG キーワード登録**で登録・送信を未然防止。 |
| 14 | 管理者への通知 | 社員が不適切物品・メッセージ・トラブルを管理者へメッセージ通知。 |
| 15 | 不適切利用の防止 | 管理者が不適切な物品/メッセージを削除。特定社員に**利用制限**。 |
| 16 | 利用状況の管理 | 出品数・成約数・成約率・カテゴリ別・時系列など**比較可能な統計**を提供。**グラフ表示が望ましい**。 |
| 17 | スマホからの状況確認 | 譲渡ごとに**ランダムで推測不能な譲渡 ID** を割当。**QR コード**と状況確認用 URL を提示し、スマホで状況確認。 |

> ※ 原文では機能見出しの「8.」が 2 回出現（メッセージ／物品登録）。本表では物品登録側を「8'」と表記。

## その他の要件

- 余裕があれば**レスポンシブデザイン**でスマホ操作を容易に。
- **利便性向上のための機能追加提案**を歓迎。

## 実装視点のキーポイント抽出

- **認証/セキュリティ**: 暗号化保存、仮パスワード（ランダム）、ロックアウト(3 回)、強制変更(仮 PW/90 日)。
- **外部連携**: 人事システム CSV 取り込み（バッチ）。
- **ID 設計**: 譲渡 ID は推測困難（UUID / ランダムトークン）。QR は譲渡 ID 入り URL。
- **通知基盤**: メール送信（仮 PW、メッセージ受信、成約）。
- **検索基盤**: 多条件検索 ＋ 管理者向け曖昧（あいまい）検索。
- **モデレーション**: NG キーワードの事前チェック ＋ 事後監視 ＋ 削除/制限。
- **分析**: 集計＋グラフ（可視化）。
